# California EV Fast-Charging Gap

Where in California is demand for EV fast charging outgrowing supply, and where should the next fast-charging sites go over the next 24 months?

Independent analysis by Noah Olivieri, SDSU Economics. Work in progress, fall 2026.

## Data sources
- Alternative Fuels Data Center (U.S. Department of Energy)
- California Energy Commission vehicle population data
- U.S. Census American Community Survey
- Caltrans traffic volumes
